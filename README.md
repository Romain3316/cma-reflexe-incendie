CMA Réflexe Incendie

Application Streamlit destinée aux collaborateurs de la CMA Nouvelle-Aquitaine - Gironde.

Fonctionnalités

sélection des organismes concernés ;

affichage des to-do lists et des documents à préparer ;

cases à cocher pendant l'entretien ;

génération d'un PDF avec une page par organisme ;

aucune conservation des données saisies.

Installation

pip install -r requirements.txt
streamlit run app.py

Logo

Ajouter le logo officiel sous l'un de ces noms :

logo_cma_na_gironde.png

assets/logo_cma_na_gironde.png

logo_cma.png

assets/logo_cma.png

L'application fonctionne également sans image grâce à un cartouche texte de secours.
